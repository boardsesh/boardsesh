# Spray story fixtures

Photos, traced hold geometry and Liz’s recorded climbs extracted from the existing
`app-stores/apple/cpp-fixtures/spray.json` pinned archive
(SHA-256 `bd05792313b9c1c7ad4b7c14b3692fa55c49b2bf8564ecad54bb23a54b89760f`).
Cherry and Bowlo use deterministic mock problems over their real hold placements.
The photograph dimensions and hold coordinates are paired; replacing one requires
replacing the other. These are the campaign’s existing owner-supplied photographs.

Only presentation data is retained. No account identifiers, request recordings,
authentication, signed URLs or live wall registry writes are needed by these stories.
