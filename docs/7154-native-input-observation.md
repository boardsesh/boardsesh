# #7154 finite CI observation

This temporary QA branch diagnoses the failed privacy-switch interaction. It is not a production fix or a full crew capture proof. The branch starts at exact failed QA `6e8c46f203385c6587dcf2669e29df1c9d611cf8` and adds observation-only JavaScript logs plus a finite harness. Root and Astra review the frozen diff before the single dispatch.

The existing measurement workflow gains `observe-session-input`. Existing modes keep their capture behavior. Observation requires an exact native cache hit with key `macOS-ARM64-screenshot-sim-app-v1-9dd78a74eb71965f2e0876a147045ef8207d824eb936ee349170ddcd54a8082a`; a miss fails, with no native build or cache save. The cached app is neither rewritten nor re-signed. Manifest hashes cover its executable, debug library and plist; SDK/runtime, CLI version, diagnostic diff hash and wrapper pre/post hashes are retained.

One new primary simulator uses iOS 26.5. One Metro uses one worker. This reduced topology and omission of normal capture work are explicit load confounders. VM, swap, query-only pressure, top-five executable RSS and actual booted-device topology are sampled immediately around the experimental contact, with sensor start/completion timestamps. Unsupported sensors are null. The job is capped at 30 minutes; the harness has a 23-minute deadline and bounded command/process cleanup.

The primary uses the same existing authorized live test account as the failed capture. The user authorized unattended investigation; the auth-only exception is necessary to authenticate that account. A loopback proxy allows only exact native credential, refresh and revoke endpoints plus live GraphQL queries/subscriptions and static GETs. Registration, identity changes, GraphQL mutations and other application writes are blocked. Only blocked operation names/counts survive. Blocked side effects remain a documented confounder; they are never silently enabled. The harness never presses Start, creates/joins/ends a session, prepares a secondary, resets credentials, or writes LEDs. Screenshot fake BLE is enabled. Missing existing repository credentials stop the experiment without guessing.

Before each experimental input, the harness requires a unique, enabled, checked-ON native visibility parent, its observed thumb and verified foreground bundle. Point `(369,487)` is used only if that fresh thumb contains it. Otherwise the observed parent's trailing relative point must also be inside the observed thumb. The current row screenshot and sanitized geometry are retained. Exactly one point command has repeat=1 and retryTapIfNoChange=false. Pinned Maestro 2.6.1's pointer contact is configured as 0.1 seconds; the separate XCTest synthesis elapsed time is reported. Physical contact duration is not measured. The app is observed for ten seconds after command completion.

Logs trace raw wrapper value, captured disabled, before/after haptic without wrapping exceptions, parent start guard, queued state, committed state and unique runtime/mount/attempt IDs. A missing hop, changed instance, mismatched state or unverified input stops that first attempt. Only a fully successful first attempt permits one fresh launch and a second input. No third attempt exists. Failure of a post-tap screenshot/hierarchy cannot erase the observed callback boundary.

Only `.boardsesh/session-input-observation/public/` is uploaded. It contains allowlisted trace fields, generic visibility booleans/labels and geometry, black-masked row screenshots, timings, pressure, native metadata/hash/input manifest, reviewed source diff and cleanup/result status. The private directory contains raw process/debug data and the bundle is never retained as an artifact. Raw Metro/Maestro logs, auth payloads/responses, headers, variables, credentials, environment dumps, whole hierarchies and native binaries are excluded. Normal frame/raw-log uploads, rendering and timing jobs are disabled in observation mode. A completed diagnostic job is not a green crew capture proof; inspect `result.json` for reproduced versus non-reproduced boundaries.
