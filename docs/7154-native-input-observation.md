## Corrected finite observer contract

The ported original SDK26.5 app passed the six bounded local transitions with exact QA6e8 JS/wrapper bytes. Its unchanged debug library and linked SDK narrow the native-binary hypothesis for this iPhone flow, while local load, replay account and launcher/signature adaptation remain confounds. That result does not resolve the failed LIVE crew proof.

The observer now requires the existing direct Home signal carrying a fresh diagnostic runtime ID. Metro console lines are supplemental evidence. A separate loopback HTTP channel accepts only bounded stage/boolean/identity/counter packets (8KiB, four events per packet, 512 total events). The target baseline must contain one active pre-session parent and its semantic `session-visibility` row, both ON with disabled/start guards false. A challenge acknowledgement must prove the same runtime has delivered a contiguous source sequence with an empty queue and zero drops/errors before contact. Stale Home signals, other ON controls and replacement rows cannot authorize input.

Diagnostic events enter a bounded fire-and-forget source queue. A one-second health ticker runs only while the observed pre-session view is mounted. The sink returns baseline/post-window challenges; source acknowledgements follow previously queued events and include source-sequence/queue/drop/error counters. Each request has a one-second diagnostic deadline, with timer/abort cleanup on completion or unmount. Enqueue, serialization and HTTP failures are caught only inside diagnostic work; actual haptics and parent callbacks remain synchronous and their exceptions propagate unchanged.

After the fixed ten-second observation window, another drained same-runtime acknowledgement is mandatory. Source gaps, dropped/overflowed events, malformed/rejected/timed-out delivery, unmount/remount or a missing acknowledgement yield `trace_transport_unverified`. Application events delivered after the closed window cannot heal a result. The before-contact Maestro hook asserts its HTTP gate succeeded, so a rejected baseline stops before the tap. Initial/failure pressure, phase and redacted channel/counter metadata survive independently of console forwarding. This adds observer scheduling/network overhead, which remains a confound.
