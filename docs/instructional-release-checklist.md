# Release instructional video checklist

Copy these five tasks into a linked GitHub issue for every minor or major release. Link it to the living video parent [#6330](https://github.com/boardsesh/boardsesh/issues/6330).

1. **Choose the changes:** confirm the shipped source commit and release notes. Pick three to five teaching beats that show what a climber gets. Update the evergreen recipe if the feature belongs in the general walkthrough.
2. **Capture Android:** add the episode and any new Maestro flow. Seed the needed demo state, assert the real result, and capture from the pinned release checkout. Review each mark, highlight and feature claim. Keep iOS as a linked task when macOS capture is needed.
3. **Record human voice:** generate the pack, record one named sentence per beat, and review spoken wording against the actual app. Reuse the supplied music and marketing stage.
4. **Review the exports:** render the overview and chapter cuts, check duration, muted subtitles, music ducking, portrait framing and cover. Keep drafts visibly marked until narration and music are complete.
5. **Publish the edition:** dry-run the bundle, publish immutable assets and the verified latest pointer to R2, then upload the approved MP4 to Instagram manually. Attach the edition URL and Instagram URL to the issue.

The first release episode is tracked in [#6335](https://github.com/boardsesh/boardsesh/issues/6335), after the evergreen Android edition. No release-triggered CI upload is configured.
